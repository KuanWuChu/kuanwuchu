我是 **朱冠伍（Kuan-Wu Chu）**，目前就讀 **國立政治大學資訊科學研究所**，預計於 **2027 年 6 月**取得碩士學位。我的研究與工程興趣涵蓋 **多模態 AI、電腦視覺、影像復原、AI 系統、AI Agent 與異常偵測**。

我特別關注如何把研究方法從原型推進成 **可評估、可最佳化、也能真正部署的系統**。近期經歷包含在 **台積電（TSMC）**進行資料庫與 Job Dispatch / Queue 異常偵測並參與系統落地、在 **和碩（PEGATRON）**開發瀏覽器自動化 Agent 與可重複使用的 skills，以及在 **工研院（ITRI）**進行即時電腦視覺與 TensorRT 推論最佳化。這些經驗讓我同時累積了研究、模型實驗、效能優化與實際部署的完整經驗。

### 研究與工程方向

- **多模態 AI / 電腦視覺** —— 偵測、追蹤、影像復原、視覺語言模型與即時影片理解
- **高效率 AI 系統** —— TensorRT、Edge AI、模型加速與 production inference pipeline
- **AI Agent** —— Tool-calling LLM、瀏覽器自動化、Reusable Skills、工作流程設計與評估
- **時序與異常偵測** —— 資料庫事故、Job Dispatch / Queue 異常，以及視覺瑕疵偵測

### 代表成果

- 在 **台積電**建立 Oracle Database 異常偵測流程，並將 Job Dispatch / Queue 異常偵測系統部署至正式環境；測試集達到 **97% detection accuracy**，且 **無 false-positive alerts**。
- 在 **工研院**以 TensorRT FP16 最佳化 Jetson Orin 上的 **RF-DETR**，達到 **7.50× end-to-end throughput**、**4.03× model-only inference speedup**，並降低 **75.2% latency**，同時維持近乎一致的偵測準確度。
- 在 **和碩**將瀏覽器自動化 Agent 抽象成可重複使用的 skills，並設計 retry、error handling 與 evaluation flow，供 tool-using LLM 與 agent workflow 使用。
- 研究成果包含 **CVPR Workshops 2025（SyntaGen）**、**第一作者 IEEE ICS 2024** 論文，以及台灣發明專利 **I912159〈社交活躍度檢測系統以及方法〉**。
